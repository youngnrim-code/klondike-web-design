# KLONDIKE INC — Smart Store Solutions Website

A modern, responsive marketing website for **KLONDIKE INC**, a smart-store
solutions company (kiosks, ordering, POS, payments, and store operations).

The site reimagines the information architecture of a smart-store solutions
provider — rebuilt with original copy, a premium "gold-on-ink" design system,
custom SVG iconography, and a stronger UI.

## Pages

| Page | File | Purpose |
| --- | --- | --- |
| Home | `index.html` | Hero, value props, solutions preview, testimonials |
| Solutions (What) | `solutions.html` | Full 18-solution catalog in 3 categories |
| Why Klondike (Why) | `why.html` | Value propositions & 24/7 support promise |
| Where We Work (Where) | `where.html` | Industries served & case studies |
| Company | `company.html` | Mission, values, story & corporate details |
| Let's Talk (Let's) | `contact.html` | Consultation form, contact info & FAQ |

## Tech

- **Zero build step** — plain HTML, CSS and vanilla JS. Open `index.html` or
  serve the folder statically (e.g. GitHub Pages).
- `assets/css/styles.css` — design tokens + components.
- `assets/js/main.js` — shared header/footer, mobile nav, scroll-reveal,
  animated counters, accordion and the demo form handler.
- Fonts: Sora + Inter via Google Fonts.

## Run locally

```bash
python3 -m http.server 8000
# then open http://localhost:8000
```

## Notes

All product names, copy, testimonials and statistics are illustrative content
created for KLONDIKE INC. Icons and graphics are original inline SVG.
